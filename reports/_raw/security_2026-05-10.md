# Security Audit Raw — wim-android — 2026-05-10

## P0 — Critical

### SEC-001 — Plaintext API keys in APK assets
Files: app/src/main/assets/api_key.txt, app/src/main/assets/anthropic_key.txt, WimApp.kt:33-55
Live OpenAI and Anthropic keys bundled in APK assets. Extractable from any APK via unzip.
Fix: Revoke both keys. Remove bundledKey() from WimApp.kt. Use backend path exclusively.

### SEC-002 — WimTestReceiver exported unconditionally
Files: AndroidManifest.xml:113-118, WimTestReceiver.kt:50-53
exported=true with no android:permission. Any installed app can broadcast com.wim.app.TEST.
Capabilities: inject_raw, set_pref, trigger_clarifier, click_send, toggle_recording, export_sessions.
Only defense is BuildConfig.DEBUG runtime check — bypassable via APK repackaging.
Fix: Move receiver declaration to app/src/debug/AndroidManifest.xml.

### SEC-003 — AgentSocketServer unauthenticated on loopback
Files: agent/AgentSocketServer.kt:29,70, agent/AgentCommandHandler.kt:42-58
Listens on 127.0.0.1:9222, no auth token required. Any app with INTERNET permission can connect.
Fix: Token on first line, or switch to LocalServerSocket (Unix domain socket).

## P1 — High

### SEC-004 — Path traversal in inject_audio / inject_raw_file
Files: WimTestReceiver.kt:195-226, WimTestReceiver.kt:228-252
audio_path/raw_path not canonicalized. Attacker can read any file the app can access.
Fix: Canonicalize and restrict to allowed directory before use.

### SEC-005 — Keystore password in plaintext
Files: app/build.gradle.kts:22-28
"wimstore2026" committed in build file.
Fix: Move to keystore.properties, add to .gitignore.

### SEC-006 — Session export path traversal
Files: WimTestReceiver.kt:382-387
output_path override in export_sessions writes raw speech transcripts to attacker-controlled path.
Fix: Remove output_path override, always write to app's private filesDir.

## P2 — Medium

### SEC-007 — Firebase API key unrestricted
Files: app/google-services.json:30-32
Key AIzaSyD2fSjQZT76sJ5yYL6CRgXxE7ejlCP-Acg not restricted to package+cert.
Fix: Restrict in Firebase Console. Audit Firestore Security Rules.

### SEC-008 — set_pref allows arbitrary key injection
Files: WimTestReceiver.kt:399-423
No allowlist on pref key. Attacker can overwrite api_key preference.
Fix: Add explicit allowlist of settable keys.

### SEC-009 — No certificate pinning
Files: ReconstructClient.kt:18-21, WhisperClient.kt:27-31
System trust store only. Vulnerable to HTTPS interception on compromised devices.
Fix: Add CertificatePinner for api.openai.com and api.anthropic.com.

### SEC-010 — AgentEventBridge emits password field keystrokes
Files: agent/AgentEventBridge.kt:30,52-57
TYPE_VIEW_TEXT_CHANGED emitted without isPassword check.
Fix: Guard with source?.isPassword == true check.

### SEC-011 — Session data (raw speech) in Firestore without encryption
Files: SessionHistory.kt:145-167
raw_text contains verbatim disfluent speech stored unencrypted in Firestore.
Mitigated by correct auth rules but not defense-in-depth.

- Password field injection guard: present in BubbleService (isPasswordField check)
- BubbleService exported=false: correct
- BootReceiver exported=false: correct
- WimAccessibilityService permission=BIND_ACCESSIBILITY_SERVICE: system-only, correct
